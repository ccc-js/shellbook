# v0.7 — fullstack-github：加上 GitHub 實戰

> 目標：把 fullstack 練習延伸到 GitHub——授權、建倉推送、fork＋PR、Actions CI/CD。
> 模式：terminal 有權限就自動執行；沒權限就印手動指引，由學習者在瀏覽器完成。
> 測試：新增 3（靜態守衛＋全書真跑），全套 123/123 綠。

## 交付

- `books/fullstack-github/`（9 章 23 範例：前 5 章沿用＋4 章 GitHub 實戰）
  - ch06 授權：`gh auth status` 診斷（自動）＋`gh auth login` 瀏覽器流程
    （手動，寫成無標籤 fence 不可點）＋`git ls-remote` 連通性檢查。
  - ch07 建倉推送：`gh repo create/view` 冪等建倉＋掛 origin＋push；
    手動分支只印指令由學習者貼上跑。
  - ch08 fork+PR：fork `octocat/Spoon-Knife`→clone→分支→push→`gh pr create`
    （重跑不重開）；合併留給瀏覽器手動收尾。
  - ch09 Actions：`gh workflow/run list` 只看不追（`watch` 會等穿）、
    README 徽章本地改檔＋commit。
- 作者模式（`_doc/BOOK.md` #10，guarded-auto＋手動並陳）：
  mutating 指令包 `if gh auth status`，兩分支各 echo 狀態 token
  （`GH_LOGGED_IN`／`GH_NEED_LOGIN`），`expect:GH_` 兩條路都綠；
  `gh auth login` 不可執行、`gh repo delete` 禁止、手動分支不執行只印指令。
- `src/steps.js` compound 升級：if/for/while/until/case/`{}`/`()` 沒閉合不切
  （引號註解 heredoc 排除，寧多併不多切）＋5 項單元測試；
  runnable 塊內 `gh` 全加 `TERM=dumb` 前綴（v0.4 舊坑復發即修）。
