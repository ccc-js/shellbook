# v0.3 — Book ↔ Shell 連動（點書即跑）

> 目標：本版是「啊哈時刻」——點書即跑 shell，可單步可全跑。
> 對應 `plan0.x.md` 的 v0.3。測試：新增 15（切行單元 6＋run/step e2e 9）。

## 交付

- `src/steps.js` — code 切邏輯行：空行略過、`\` 續行合併、
  heredoc 整段合併、未閉合寬容、純註解保留。
- `src/runner.js` — FIFO 執行佇列＋exit code 擷取：
  每行後跟 `echo __SHELLBOOK_END_<seq>__:$?` marker，從 pty 流切出結束點；
  `run` 失敗即停，`step` 每 ws 一個游標（換 block 自動重置＋`reset`），
  單行超時 30s→Ctrl+C→回報 timeout，空 code 回 error 不卡佇列。
- `server.js` — `run/step/reset` 三訊息（pty 輸出同時廣播＋餵 runner 嗅探）。
- 前端：block 三鈕「單步 ▶|／全跑 ▶▶／複製」，
  執行中按鈕互斥（防交錯）、逐行綠／紅高亮、進度列
  （`全跑中 2/5…`／`✓ 全跑完成`／`✗ 第 2 行失敗已停止`）、
  單步鈕變「下一步 (2/5)」。

## 測試

- `test/steps.test.js`（6）：切分／續行／heredoc（含 `<<-`／引號）／註解／空程式／未閉合。
- `test/v03.test.js`（9，真 pty）：單行／多行／續行／heredoc 全跑、
  失敗即停且第三行確實沒跑、空 code、單步游標推進、換 block＋reset、
  雙 run 排隊有序、手打與 run 混送不崩。

## 已知限制

- marker 行會出現在 terminal（互動式 pty 的正常代價）。
- 執行中手打仍會送出（前端 busy 提示，嚴格隔離等 v0.5）。
- `if/fi` 等 compound block 還不會切（v0.7 補上）。
