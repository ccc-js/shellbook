# v0.5 — 安全與多 session

> 目標：敢給別人用、不怕一本書毀掉整台電腦。
> 對應 `plan0.x.md` 的 v0.5。測試：新增 60（guard 單元 48＋session e2e 12）。

## 交付

- `src/guard.js` — deny-list：`rm -r` 系統目標（含 `/etc/hosts` 類前綴、
  `"..."` 引號目標）、`mkfs`、`dd of=/dev/*`、關機三兄弟、fork bomb、
  裝置重定向、`chmod/chown -R /`；拆 `&&/||/;/|` 逐段查、遞迴查 `$()`／反引號；
  引號包住的純字串放行，裸危險詞寧嚴勿鬆。
- `config/shellbook.json` — 上限／閒置／超時／輸出上限／warn 清單，
  全可被 `SHELLBOOK_*` env 覆寫。
- 後端 session 化：每 WS 一 session（獨立 pty＋Runner，
  沙盒 `workspace/sessions/<id>/`，`$SHELLBOOK_WS` 指向它）；
  `?session=` reattach、上限拒絕、閒置回收、`DELETE` 連目錄清掉、
  `logs/<id>.log` 記 run/step/input/blocked＋exit code。
  run/step 整塊原子預檢；手打逐字轉發、Enter 判整行（危險送 Ctrl-U 吃掉，
  bracketed-paste 解包再判）。
- 前端：session 下拉＋＋／－鈕、cwd 顯示、危險範例二次確認
  （warn 清單來自 `/api/config`）、blocked 紅字、session 被收掉自動開新。
