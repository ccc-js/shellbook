# v0.6 — 學習體驗：進度、對照、筆記、打磨

> 目標：從「能跑」變「好學」。
> 對應 `plan0.x.md` 的 v0.6。測試：新增 8（progress 單元＋expect/notes e2e＋前端靜態）。

## 交付

- `src/progress.js`＋3 支 API：後端在 run/step 完成時自動記
  （`progress/<book>.json`，跨 tab 共用，重進還在），含 done/failed、
  exitCode、次數；`DELETE` 可按章或整本重置。
  （以後端為唯一真相源，比 plan 的 localStorage 更能跨 tab 同步。）
- expect 自動對照：run/step 帶 book+ch，後端累積該 block 輸出、查書上
  `expect:` 關鍵字，回 `{type:'expect', met}`；前端顯示
  `觀察「hello」✓ 出現了`，徽章同步 `觀察✓/✗`。
- 筆記匯出：audit 補記每步 output（2KB 上限）；
  `POST /api/notes/export` 把 session 紀錄組成 `notes/<date>.md`
  （範例＋逐行 exit＋輸出＋被阻擋清單），選單［匯出筆記］一鍵下載。
- 前端打磨：章節頂部進度條（`本章 3/5 完成`）＋［重跑本章］［重置］、
  code 行號＋註解色、`⌘/Ctrl+Enter` 全跑／`Shift+Enter` 單步、
  失敗時一句話提示（not a git repo→ch02、CONFLICT→ch03…共 7 條）。
