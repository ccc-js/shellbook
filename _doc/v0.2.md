# v0.2 — Book 載入與渲染（還不執行）

> 目標：定義書的格式，前端能看書、能列出可執行範例。
> 對應 `plan0.x.md` 的 v0.2。測試：新增 16（parser 單元 7＋API/插入 e2e 9）。

## 交付

- `_doc/BOOK.md` — 書籍規範初版：`books/<name>/book.json＋chapters[]`，
  fenced code info string 標籤 `#run/#step`＋`cwd:/expect:`，
  無標籤／空 block 不收，id=`<章基名>-<序號>`。
- `src/books.js` — book.json 驗證＋fence 抽取＋`../` 跳脫防護。
- `books/demo/` — 範例書 2 章 4 範例（全是真能跑的指令）＋1 個無標籤純展示塊。
- 後端 API（唯讀）：`GET /api/books`、`/api/books/:name`、`/api/books/:name/ch/:ch`
  （可省略 `.md`；404/400 完整）。
- 前端：功能表書籍／章節選單啟用，`marked` 本地渲染；
  runnable block 掛「插入↓／複製」＋模式徽章＋cwd/expect 提示。
  **v0.2 刻意只插入不自動執行**（不帶換行，使用者按 Enter 才跑，安全第一）。

## 測試
